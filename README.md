# software-testing-lab

# Практична робота: Створення автоматизованого тесту за допомогою ШІ

**Об'єкт тестування:** Сайт Карпатського національного університету (https://cnu.edu.ua/)

## Опис автоматизованих перевірок:
1. **Перевірка заголовка:** Скрипт відкриває головну сторінку та перевіряє, чи містить title слово "університет".
2. **Перевірка наявності елемента:** Скрипт шукає посилання "Новини" і перевіряє його видимість на сторінці.
3. **Клік та перехід:** Скрипт клікає по знайденому посиланню та перевіряє, чи успішно змінився URL сторінки після переходу.

## Інструкція із запуску тесту:
1. Встановіть Node.js на свій комп'ютер.
2. Відкрийте термінал у папці з проєктом.
3. Встановіть залежності командою: `npm install playwright`
4. Встановіть браузери для Playwright: `npx playwright install chromium`
5. Запустіть тест командою: `node tes1t.js`

**Використаний інструмент ШІ:** Gemini
